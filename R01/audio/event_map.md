# 第一轮音效设计 · 独立概念小样

状态：本轮原创程序合成素材，可试听，尚未接入 Godot。未进行人工听评、手机扬声器试听或实机验收。全部音频为 44.1kHz / 16-bit PCM / 单声道 WAV。声音是同一套机制提示，供三种视觉方向共享比较；不声称已制作三套不同声音。

## 声音与事件

| 文件 | 时间 | 概念与源码接入位置 | 触发方式 |
|---|---:|---|---|
| cloud_transfer.wav | 0.30s | 下滑短电子啸声；UnluckyDuck.contact 中持云者切换 | 仅切换成功时一次，跟随新持有者声像；不是每帧播放 |
| lightning.wav | 0.65s | 短电噪爆裂与低频尾声；UnluckyDuck.strike | 放电发生时一次；被避雷针吸收仍可播放放电，但不播放角色受击声 |
| rabbit_charge.wav | 2.00s | 低音脉冲逐渐升调；进入 action=forge 的两秒强化锻造 | forge 开始播放一次，状态提前退出时短淡出；不是蓄满提示 |
| rabbit_hit.wav | 0.48s | 重低频锤击，带短金属尾音；ForgeRabbit.contact 有效敌方接触 | 按实际结算一次触发；零储存伤害不播放“重击” |
| forge.wav | 0.20s | 轻金属敲击；锻造表现动画敲击帧 | 可替代 charge 持续声中的节拍，避免二者叠加过响 |
| temper.wav | 0.42s | 上行三音提示；temper_left 从 0 进入 3 秒 | 仅起效一次；到期用视觉结束，无需第二个声音 |

源码依据：`/workspace/balls/scripts/unlucky_duck.gd`、`forge_rabbit.gd`。鸭初始雷云周期7秒；计时技能按持有者增减2秒，所以声音不可按固定7秒自循环。兔被动8伤害/秒，forge状态12伤害/秒、持续2秒；蓄力没有上限；淬火持续3秒，使接触释放倍率为1.5；有效接触后储存伤害及淬火清零。小样的2秒只表现forge状态，并不将兔定义为2秒蓄满或自动攻击。

## 建议混音与接入约束（待点点实现）

- 单个音源已有峰值余量；多音叠加仍可能削波。建议 SFX 总线初始 -6dB，并配置 limiter，再由实机听评调校。
- 默认把雷击与有效重击作为重要提示；同帧两者都发生时保留事件语义，可将锻造底声压低6dB、持续约120ms。不延迟实际命中反馈。
- 每角色锻造底声只允许一个实例；雷云转移声按真实转移事件触发，不按画面检查轮询；碰撞抖动去重必须以游戏事件唯一标识为依据，不能吞掉合法连续碰撞。
- 声像以角色水平位置映射至约±0.5，单声道设备应仍保留声音；不依靠声像作为唯一归属信息。
- 暂停同时暂停持续音，恢复后同步剩余状态；倍速需明确选择时间拉伸或重触发策略，不能默认提高音高。关闭声音后信息仍由图标、文字、数值提供。
- WAV 可无缝被大多数引擎读取，但本轮没有验证 Godot 导入、Android 延迟、设备音量或总线限幅。

## 实际检查

`audio_metrics.json` 记录每个导出 PCM 文件的持续时间、峰值、RMS 与削波样本数；全部6个文件的削波样本数为0。数字测量不等于主观听感通过。可用 `index.html` 点击试听；浏览器需用户手势，禁止自动播放。不同声音试听自动停止前一条，以便比较。
