# 第一轮角色与物件概念素材

本目录所有 PNG/GIF 均为本轮 Python/Pillow 程序原创像素绘图，无第三方图像采样。不是正式游戏素材，不是实机截图，尚未导入 Godot。生成源码为 generate.py。

A 暖色玩具街机：明亮黄鸭、紫兔与珊瑚点缀，推荐用于首轮可读性验证。B 暮色锻造工坊：鸭子矿灯、兔子护目镜、低饱和金属及暖火花。C 青紫霓虹竞技：发光目镜、角色服饰发光条、冷色金属。

每帧 64×64 RGBA；底层32×32像素格放大2倍，禁止平滑采样。每个 _strip.png 为256×64、左至右4帧；idle建议6fps；cast/charge为状态小样，impact为关键姿态。不应把示范帧率当成实际技能时序。GIF为循环姿态预览；impact为固定关键帧，后续需制作完整回收动作。

脚底基准约y=60，角色朝右；面朝左可在接入阶段评估翻转。鸭子状态 idle/cast/impact，兔子 idle/charge/impact；避雷针与铁砧单帧。各状态首帧另有独立PNG，duck.png与rabbit.png是默认静态入口。
