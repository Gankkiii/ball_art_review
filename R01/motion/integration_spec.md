# 动效与技术美术｜第一轮交付

性质：独立离线概念预览与可实现的素材小样，不是 Godot 录屏，不是完整战斗模拟，不是 Android 实机验收。未修改游戏仓库。

## 直接查看

- `index.html`：解压整个交付包后，用现代浏览器打开；相对路径需要保留 character 与 audio 同级目录。可切换三方向、播放/暂停/重播、拖动进度、半速、静音。手机文件管理器的 HTML 沙盒可能限制同级资源读取，可用 `demo_A.mp4` 直接观看。
- `demo_A.mp4`：甲方向 960×540、15fps、约8秒，内含音频，供 PPT 链接或嵌入。
- `demo_mix.wav`：独立混音，44.1kHz、单声道、16bit。
- `frames/`：121帧，可回溯对应时间点。

## 编排时序与源码关系

读取依据：`scripts/unlucky_duck.gd`、`scripts/forge_rabbit.gd`。本片固定碰撞时刻，只取技能事件演示，不模拟真实位置、基础碰撞伤害、防御或全部状态。血量100仅为展示起点。

| 时刻 | 展示事件 | 数值依据 |
|---|---|---|
| 0秒 | 雷云归鸭；兔开始积累 | 初始倒计时7秒，基础积累8/秒 |
| 1.8秒 | 接触，云转兔；兔释放当前伤害并清零 | 8×1.8=14.4 |
| 2秒 | 兔开始两秒锻造；鸭放避雷针 | 锻造期间积累12/秒；避雷针不覆盖远处兔子 |
| 3秒 | 鸭改时，雷云在对手身上 | 剩余4秒减2秒，预计5秒落雷 |
| 4秒 | 锻造结束 | 存储1.6+24=25.6，之后恢复8/秒 |
| 5秒 | 兔遭落雷；云回鸭；兔淬火 | 伤害32；云重置7秒；淬火持续3秒 |
| 6秒 | 第二次接触；云转兔；兔重击 | 存储41.6×1.5=62.4，释放后存储及淬火清零 |
| 8秒 | 结束并停止 | 不自动续播 |

雷云特效保持0.25秒，与当前 `lightning_flash` 一致。重击爆发视觉0.4秒为待选美术提案，不更改游戏逻辑。现有碰撞属于接触即命中，接入时不得为了播放挥锤延后伤害。

## 图层与采样

背景地板 → 地面阴影/范围 → 避雷针 → 角色 → 角色状态 → 雷云/落雷/重击火花 → 顶部HUD。角色帧64×64，底层32px网格；横向帧条256×64、四帧、8fps；nearest，无平滑，整数显示比例。兔角色可水平翻转，不翻转HUD文字。当前impact帧条是关键姿势重复，并非完整挥锤循环，下一轮需补预备/接触/收势。

## 接入事件与音频

| 游戏状态或事件 | 动画 | 声音 |
|---|---|---|
| `cloud_holder` 改变 | 云归属箭头/瞬时轨迹 | cloud_transfer.wav |
| `strike()` | 定点闪电0.25秒；保护成功需另做吸收版本 | lightning.wav |
| `action == forge` | 两秒充能火星与姿态 | rabbit_charge.wav；forge.wav作为锤击点缀 |
| `temper_left > 0` | 暖色脚环、×1.5文字 | temper.wav仅进入时 |
| 兔 `contact()` | 碰撞爆发、飘字、stored归零 | rabbit_hit.wav |

本片每条音轨0.5增益；混音峰值0.562（未削波）。暂停、拖动进度、切换速度、页面隐藏都停止当前声音。页面隐藏自动暂停。静音默认开启，用户点击后才尝试声音播放；浏览器拒绝声音时不会将其伪报成功。半速音频使用播放速率0.5；浏览器可能保留音高，本轮没有指定preservesPitch或听评此行为，不代表最终倍速音频策略。

## 验证与未验证

已在桌面 headless Chromium 加载，0条JS异常；方向切换、播放、暂停、声音开关状态、半速设置、重播6项状态检查通过。Canvas导出121帧，人工查看5.33秒帧，角色/HUD/云/蓄力文字清晰且无重叠遮挡。FFmpeg编码成功，音视频流经ffprobe检查。音效仅验证文件编码、合成混音和峰值，未声称人工听审通过。

未验证：Godot实际导入、自动战斗中的高密度遮挡、低端Android帧率、手机音频策略、色弱用户识别、强光/闪光舒适性。接入前需确定逻辑事件接口、角色显示尺寸和音频总线；建议增加减弱闪光开关。当前预览不会连续全屏白闪。

来源：角色素材来自同轮character岗位，音频来自同轮audio岗位；本岗位场景、代码、编排与混音为本轮原创，无下载第三方视听素材。详细资产记录以对应岗位清单为准。
