## 已存在机制

- 每1秒掉铁钉，初始nail_timer0.5；静止铁钉没有踩踏伤害。
- MAGNET WALL随机磁化一面墙，已有自己的铁钉先到墙边，再返回蟹位置，CD7。
- RETURN REPEL准备弹下一枚回来的铁钉，向敌人当时位置方向飞0.8秒后落静止；准备态不反复刷新，CD6。
- 铁钉仅实际移动才伤敌，伤16、单枚命中间隔0.3秒，速度320；用轨迹线段检测。普通返身回收后消失。
- 铁钉遇敌稻草人会在其前方停住，mode转rest，不消失。
