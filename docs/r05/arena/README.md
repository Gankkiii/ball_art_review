# R05竞技场：四个未选候选

四张主图和四张信息展开图均为1600×900概念效果图，非实机截图、非已接入素材包。图中角色、羊毛与场地使用项目R04原始PNG，以程序绘制新布局并导出SVG/PNG，没有从展示截图裁素材。

统一示例：泡泡鱼110/120HP、CD3.8/7.8；触电羊120/120HP、CD1.8/4.8、电量17.5/100；11个泡泡（10个1级、1个3级），羊毛一处。种子3103、时间5.3只用于信息展开，不声称这些示例可共同从真实轨迹复现。所有方案世界都是700×600等比1:1，只改变界面位置。泡泡等级没有上限；羊的电量上限100。

- A「转播席」：头像、HP、资源和双自动技能全部进入顶部横向计分条，场边无状态卡；底部只留公共控制。连续扫读方便，但视线需上下切换。
- B「双边卡片」：延续已选左右方向，双方整卡对应角色，底部控制。归属清楚，但占用两侧空间。
- C「单侧控制塔」：世界左移，双方信息进入右塔，操作纵排右侧。适合右侧集中操作，但信息密集且重心偏左。
- D「英雄控制坞」：HP、资源和技能下沉双角色坞，控制进入右上。战场上部干净，但视线需下看CD。

四案都有竞技场/主线/仓库/孵蛋导航；暂停、1×/2×/3×、重看、新局、声音开关与信息入口。技能图标仅自动技能冷却展示，不是手动施放按钮。声音图标表示当前开启，暂停图标表示当前可暂停；另一状态复用项目已有play/mute原件，不在主图重复堆叠。信息展开包含种子、时间、角色技能与资源解释，关闭回到原界面；此图不代表新实现了暂停逻辑。页面切离竞技场的已有暂停与停音、返回不自动恢复规则仍需保留。

`review.json`为网页索引；`a..d/main.svg`与`info.svg`均内嵌PNG可独立编辑；`source/build.py`和`source/assets/`为制作源。复制完整arena或仅source到新目录，安装Python3/Pillow及Inkscape后运行`python3 source/build.py`即可重建。字体为环境已有Noto Sans CJK SC；接入沿用项目已授权字体，不新增字体授权声明。

未验证：Godot接入、窄屏适配、设备触控、动态遮挡、密集物件压力和性能；现有物理、玩法和角色设定均未修改。当前推荐只供选择：B风险较低，A观赛层级更清晰，最终由用户决定。
