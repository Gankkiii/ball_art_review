# R03 后四角色评审图源

范围：仙人掌、脱壳龟、磁铁蟹、乌鸦；每个角色2种轮廓不同的A像素风候选，独立物件、关键状态、2种重点反馈与2种受击反馈。**网页评审ONLY，所有候选未选，不是接入素材包或游戏录像。**

## 原创制作与文件

- `build_last_four_review.py`：本轮原创几何绘图源，没有图片/视频输入、没有截取历史评审图，也没有修改正式游戏。
- 每个角色目录的`variant_[ab]_sprite.png`是96×96 RGBA候选源图，SVG同名可编辑；384×420候选卡与768×530对比板是说明预览，不能代替直接接入素材。
- `object_*.png/.svg`是独立候选物件。龟本体和空壳分别绘制，旧锤兔等不在本轮八角色设计中混用。
- `motion_[12].gif`每个为12逻辑帧×120ms的无声概念循环；`hurt_[12].gif`为8逻辑帧×80ms。GIF可能合并相同画面，实际编码帧数与总时长已写`review.json`；不把逻辑帧数称为独立姿势数量。
- 状态/反馈统一用A候选控制变量，不代表A已选；B完整动作、连续移动动画、Godot接入、实际音画同步与真机均未完成/未验证。只有八角色造型/动效概念评审，不扩大为新一轮游戏开发。

## 重建

已执行环境：Python3.12、Pillow12.3.0，预览文字由系统Noto Sans CJK SC（OFL1.1，TTC face2）渲染。字体文件不再分发，文字不作为游戏字体资产。

将本轮`facts/{cactus,shell_turtle,magnet_crab,crow}.md`复制到一个外部空目录，例如`/tmp/r03-last-four/facts/`，执行：

```sh
python3 build_last_four_review.py --root /tmp/r03-last-four
```

程序只读取独立事实文档，按原机制制作候选外观；不要把输出目录指向正式游戏。事实稿和另岗维护的`SETTING.md`是本轮代码核对文档，不由绘图程序虚构或生成角色故事。图片/动画/JSON新目录重建94文件逐字一致，见`last_four_reproduction.json`；57PNG、17SVG、16GIF读取/解码与路径、事实哈希核对通过，见`last_four_validation.json`。

## 机制边界

- 仙人掌本体固定，不制作走路；附近刺原地生成，不画持续伤害飞弹；REGROW仅换位、不回血。
- 龟本体与独立壳分离，hidden不画裸身掉血；旋壳的局部环/边缘轨迹不是高速冲刺，空壳不播放受伤。
- 蟹静钉无害、实际移动钉才伤；准备标记在回钉弹出时消耗，返程拖迹方向与概念运动一致，不给钳新增近战技能。
- 乌鸦换位只瞬换，储羽不因此消耗；羽毛仅近身修复受伤自家稻草人，不画羽弹、远程治疗或草人主动攻击。
- 所有受击仅为真实掉血后的局部压低/眨眼或碎光候选，没有新击退、hitstop、无敌、碰撞或伤害规则。

声音由总负责人统一制作试听样例；此处GIF无声，不声称与独立音频已游戏同步。颜色、材质与性格感的文字都只描述候选视觉意向，不能当作已获用户确认的新角色背景。
