**只供选方案，不是游戏实录、不是接入素材包，也没有替换旧UI。** A像素风、浅色场地、横屏、极简是共同基线。已确认的鸭兔左右侧栏仍作为方案A延续参考；方案B/C只有经用户另选才可能改变布局，不能把评审当成放弃旧决定。

## 同态公平比较

固定同一未选造型候选A（不是用户已选）：泡泡鱼与触电羊。前4角色使用96RGBA `variant_a.png`，后4使用96RGBA `variant_a_sprite.png`，没有裁384像素展示板。复用R02已交付的浅色场地和公共操作图标作为统一风格基线，不重新设计鸭兔。

`source/capture_state.gd`只在工作目录外部实例化当前真实BattleArena并按1/120步长推进，未改game代码。

- 基线：`3134f2b8dd0fe250b01e1e7d3c829da5c54aaa47`，Godot4.6.3。
- 主样例：手动固定合法组合[2,3]、seed3103，5.2583模拟秒；鱼110HP、羊120HP，11泡泡/最大等级3，羊17.5/100电、一处羊毛、真实zapping。固定组合是比较工具，不声称该seed随机抽到此组合。
- 压力样例：[8,9]、seed3108，7.0083秒；龟hidden、壳spin剩0.4833秒、乌鸦存一根羽毛与两个60HP稻草人。
- 精确浮点、位置、CD、物件、JSON与日志见`data/shared_sample.json`、`data/stress_sample.json`、`data/capture.log`。

三主图默认HUD各31个非空白Unicode字符，均为同一组HP、资源、4CD、融合泡泡等级与三个倍率；caption不计入。计数来自绘制字串，非OCR。不是把文字隐藏到截图外换取少字，只有预览说明放在画布外；状态意义、单位和术语建议按需info查看。1级泡泡不加数值/假爆炸，融合泡泡标真实等级；泡泡等级无上限，不能画“蓄满百分比”。羊电量有真实100上限，因此允许细条。

## 8角色适配与保留功能

`review.json.eight_role_adapters`按代码列充气角色、鸡、鱼、羊、蟹、仙人掌、脱壳龟、乌鸦的资源/状态含义。数量类（泡泡等级、刺、钉）不随意设上限；鸡小蛋/大蛋引信不同；龟入壳显示及稻草人/羽毛语义不能混淆。角色与图标当前只是候选，不是最终8角色完整动态UI。

每人两个技能仍为自动状态图标＋真实剩余CD，不改成点击施放。底部保留暂停、1×/2×/3×、同种子重看、新随机、声音、全部角色、信息。实际代码`main.gd`从10角色池不重复选2；当前`showcase.gd`固定鸭兔[5,6]。这里仅提议随机对战UI，不声称已把8新角色接入默认样板，也未删除任何原操作。

## 源文件与复现

`source/build_ui_review.py`读取本目录冻结JSON和`assets/`原PNG，输出自包含SVG/PNG与review.json；不读写游戏文件。SVG使用data URI嵌入原图，没有外部图片网络依赖，编辑/查看SVG不需旧任务目录。PNG采用Inkscape由SVG导出，字体使用环境Noto Sans CJK SC，未附字体二进制。需要Python3/Pillow/Inkscape及Noto字体；在用户授权的制作周期中复制整个ui到新外部目录运行即可，不要覆盖已审核版本。

`source/capture_state.gd`是采样的只读制作工具而非游戏补丁；绝对输出路径是本次工作区路径。要重抓样例需有对应游戏基线与Godot，不能把新版本新样例冒称本次固定比较状态。

## 未验证

本轮只检查静态图、源复现及数据事实。没有新增游戏行为、真实动态HUD、性能/帧率、设备安全区、触控、长数值、移动跟随抖动或动态避让验证。方案C虽在示例静态选择不遮角色的位置，不能宣称拥挤所有状态都不挡。养成、挂机等未确定玩法不放进本战斗评审。

素材来源/逐图哈希见`data/asset_sources.json`；所有新方案都是可选提案，由用户决定，不因推荐或浏览自动批准。
